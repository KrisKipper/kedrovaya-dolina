# Кедровая долина

Пример решения практической задачи по вёрстке сайта **по макету Figma**.

Проект — лендинг премиальной загородной резиденции «Сосновый бор» бренда «Кедровая долина»: первый экран, галерея, каталог, блок поддержки эксперта, карта и подвал. Вёрстка на HTML и CSS, с адаптацией под Desktop и Mobile и состояниями интерактивных элементов.

## Макет

[Макет в Figma](https://www.figma.com/)

> Подставьте сюда актуальную ссылку на учебный макет, если она отличается.

## Важно

Решений одной и той же задачи по макету может быть **множество**. Этот репозиторий — **всего лишь пример одного из** возможных вариантов: своя структура классов, приёмы сеток и адаптивности. Его не стоит воспринимать как единственно верный эталон.

## Стек

- HTML5
- CSS3 (Flexbox, Grid, медиазапросы)
- шрифт Manrope
- карта Яндекса через `iframe`

## Как открыть

Откройте `index.html` в браузере или поднимите локальный сервер в корне проекта.
